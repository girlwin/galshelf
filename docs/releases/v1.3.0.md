# galshelf v1.3.0：日语学习与游戏台词自动抓取

这次更新给 galshelf 加入了「日语学习」页面。如果你想试着阅读日文原版 Galgame，现在可以把游戏里的台词接进启动器，一边读故事，一边记录自己想学的词语。

## 本次更新

- **自动抓取游戏台词**：从游戏库选择一款游戏并开始抓取。游戏尚未运行时会等待它启动；已运行时可以直接连接。台词会实时显示在学习页面，并可跟随填入学习区。
- **选择正确的文本流**：预览不同文本流；如果抓到了角色名、菜单或其他内容，可以手动切换到台词流。同款游戏开着多个窗口时，可以选择具体进程。
- **固定句子和回看记录**：关闭跟随或点击「使用当前句」来慢慢读；最近 100 条台词可以在本次记录中回看。实时刷新不会覆盖正在填写的词语、读音和释义。
- **把台词变成学习素材**：选中台词中的文字，一键填入词语栏；填写读音和释义后保存到本地生词本，也可生成手动读音注音，或打开 Weblio 查询。
- **完善连接清理**：游戏退出后自动断开，保持等待时可连接再次启动的同一游戏。手动停止不关闭游戏；切换账户和退出 galshelf 时会停止抓取、清空本次台词。修正 Windows 上部分游戏退出状态延迟导致无法立即重开的情况。

原有的本机文件夹添加、视觉小说封面检索、分类整理、通关标签、资源网站导航、解压软件下载入口、本地账户和转区启动功能继续保留。

## 下载与开始使用

1. 下载本页附件 **`galshelf-1.3.0-win32-x64.zip`**，完整解压后运行文件夹内的 **`galshelf.exe`**。需要保留整个程序文件夹，不能只取 EXE。
2. 将自己的游戏添加到游戏库，并直接指定游戏实际运行的 EXE。
3. 打开「日语学习」。首次点击「获取抓取组件」，从 [LunaTranslator 官方发布页](https://github.com/HIllya51/LunaTranslator/releases) 获取 Windows x64 版，解压后选择其中的 `files/LunaHook` 文件夹。目录须包含 `LunaHost64.dll`、`LunaHook32.dll`、`LunaHook64.dll`；程序会先验证接口。
4. **选择游戏 → 开始抓取 → 启动所选游戏 → 推进对话**。台词不对时切换文本流；选中想学的词语，再填写读音和释义。

升级用户可将新版完整解压到新的程序文件夹，关闭旧版后运行新版。已有游戏库仍从当前 Windows 用户的固定本地资料目录读取，无需重新添加游戏；建议升级前在设置中导出游戏库备份。生词本单独保存在当前本地账户目录的 `study.json` 中。

## 数据与兼容性

- 公开程序包与源码**不包含开发者的游戏、账户、头像、收藏、个人路径或生词本**。新用户首次使用为空库，需要自行从本机添加游戏。
- 运行时的最近台词只放在内存中，退出后不保留；只有点击保存的生词及例句写入本机。不同本地账户拥有独立的生词本，切换账户会清空抓取记录。
- 不上传完整游戏文本或游戏文件。Weblio 查询会将你选择的词语交给该外部网站；VNDB 作品检索仍会发送作品查询词。
- **LunaHook DLL 不随 galshelf 分发**，需要用户选择本机兼容组件。抓取依赖游戏引擎及运行权限，目前不能保证所有 Galgame 都能读取。
- 本版的读音和释义仍由用户填写，**尚未实现自动分词、自动释义、自动翻译或 OCR**。

## 验证与源码

本版通过 66 项本地回归测试及 Electron 界面流程测试；另使用独立的 32 位、64 位日文测试窗口验证了实时抓取、文本流切换、停止与重连、账户隔离及退出启动器后的连接清理。这些测试不代表所有商业游戏都已验证。

日语学习功能复用了 **MeguLit 1.3.5** 的部分源码，并对抓取桥接代码进行了修改。组合发行采用 **GPL-3.0-or-later**，保留 MeguLit 来源说明和原 galshelf MIT 署名。详见 [第三方来源说明](https://github.com/girlwin/galshelf/blob/v1.3.0/THIRD-PARTY-MEGULIT.txt) 与 [许可证](https://github.com/girlwin/galshelf/blob/v1.3.0/LICENSE)。同版本源码可通过本页的 **Source code** 下载，桥接程序的 C# 源码及重建脚本也包含在项目内。

程序包同时保留 Electron 运行时的独立署名与许可文件 `LICENSE.electron.txt`，以及 Chromium 的第三方许可汇总。

如需核对程序包完整性，可下载附件 `SHA256SUMS.txt`。反馈抓取问题时，请在 [Issues](https://github.com/girlwin/galshelf/issues) 说明游戏名称、实际启动 EXE、运行位数、所用组件版本及现象，便于继续排查。
